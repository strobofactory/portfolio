ENGINEERING APPROACH

Build for release,
not for demos.

01

Prototype first

UI/UXは先にプロトタイプで検証し、ネイティブ実装へ進みます。

02

Managed architecture

CloudKit、HealthKit、Vercelなどマネージド基盤を優先し、運用負荷を抑えます。

03

Single source of truth

canonical sourceを定め、派生物は自動生成する構成を基本にしています。

04

Release pipeline

署名、ライセンス、更新配信、ストア公開までを開発工程として扱います。
